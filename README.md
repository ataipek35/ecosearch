# EcoSearch – Sustainable Product & Alternative Search Engine

EcoSearch is a mobile search and comparison application that estimates the environmental impact (carbon footprint and plastic waste) of everyday products and recommends certified, lower-carbon alternatives.

## Key Features
* **Multi-Modal Input:** Search products via text autocomplete, barcode scanning, or label photo upload.
* **Impact Scorecard:** Approximate estimations for carbon footprint and plastic waste.
* **Verified Alternatives:** 3 certified alternatives retrieved from official eco-label registries (EU Ecolabel, FSC, Fairtrade, Energy Star).
* **Reasoning Explanation:** Step-by-step justification explaining why each recommended alternative is greener.
